# ✈️ TravelEase – Explore the World

### Discover Destinations. Explore Experiences. Create Memories.

TravelEase is a responsive travel discovery website developed to help users explore beautiful destinations, discover holiday packages, and plan memorable journeys through an interactive and user-friendly interface.

The website offers destination exploration, travel package details, search and filtering functionality, and a clean multi-screen navigation experience.

## ✨ Features

- **Home Dashboard:** Attractive landing screen with a travel search interface.
- **Destination Explorer:** Explore six popular destinations around the world.
- **Smart Search:** Search destinations by name, country, or keywords.
- **Category Filters:** Filter destinations by Beach, Mountain, and City.
- **Destination Details:** Explore destination highlights, attractions, and travel inspiration.
- **Travel Packages:** Browse sample holiday packages with pricing and duration.
- **Package Details:** View accommodation ideas, room options, facilities, inclusions, exclusions, and itineraries.
- **Separate Page Navigation:** Switch between Home, Destinations, Packages, About, and Contact without navigating through one long scrolling page.
- **Contact Form:** Interactive form with input validation and feedback messages.
- **Newsletter Subscription:** Email validation with confirmation feedback.
- **Responsive Design:** Designed to work across desktop, tablet, and mobile screens.

## 🚀 Getting Started

Follow these steps to run TravelEase on your local machine.

### 1. Clone the Repository

```bash
git clone https://github.com/ankekavya/TravelEase.git
```

### 2. Navigate to the Project Folder

```bash
cd TravelEase
```

### 3. Open in Visual Studio Code

Open the downloaded project folder in Visual Studio Code.

### 4. Run Using Live Server

1. Install the Live Server extension in VS Code.
2. Open `index.html`.
3. Right-click and select **Open with Live Server**.
4. Your website will open in your default browser.

## 🌐 Deployment

TravelEase can be deployed using **GitHub Pages**.

Steps:

1. Upload all project files to the GitHub repository.
2. Open the repository's **Settings**.
3. Navigate to **Pages**.
4. Select **Deploy from a branch**.
5. Select the `main` branch.
6. Select the `/ (root)` folder.
7. Click **Save**.

After deployment, access the website using:

**https://ankekavya.github.io/TravelEase/**

## ⚠️ Project Limitations

- TravelEase is currently a front-end demonstration project.
- Package prices and accommodation details are sample information.
- The booking form does not create actual reservations or process payments.
- Contact and newsletter forms perform client-side validation only.
- No backend or database is currently integrated.
- External images, fonts, Bootstrap, and icons require an internet connection.
